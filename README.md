# 🤖 Deutsch AI Tutor

**Deutsch AI Tutor** is a Python-based web application built with [Streamlit](https://streamlit.io) designed to help you practice German reading, listening, and writing skills.

## 🚀 Features
*   **Reading & Listening**: Practice with German sentences and hear native-like pronunciation using Google Text-to-Speech (gTTS).
*   **Writing Practice**: Test your translation skills with interactive exercises and instant feedback.
*   **Interactive UI**: A clean, easy-to-use sidebar navigation.

## 🛠️ Tech Stack
*   **Language**: [Python](https://python.org)
*   **Web Framework**: [Streamlit](https://github.com)
*   **Speech Support**: [gTTS (Google Text-to-Speech)](https://pypi.org)

## ⚙️ Installation & Local Setup

If you want to run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd deutsch-ai-tutor
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the app:**
   ```bash
   streamlit run app.py
   ```

## 🌐 Deployment
This app is optimized for [Streamlit Community Cloud](https://streamlit.iocloud). Simply connect your GitHub repository to Streamlit Cloud for free hosting.
